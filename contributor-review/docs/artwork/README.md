# Contributor artwork review candidate

The preview is generated by `ContributorArtwork.svg`, the same renderer embedded in `tokenURI`. The circular canopy and trunk are a compact vector interpretation of `public/bittrees_logo_tree.png`. No external image host or mutable image URL is required.

- Four contribution levels: Advisor, Part Time, Half Time, Full Time. Text and one through four filled markers distinguish them; markers identify the level, not a numeric compensation formula.
- Three recognition ranks: Contributor, Senior Contributor, Lead Contributor. Text and one through three border lines distinguish them.
- Four standings: Active (green), Suspended (ochre), Ended (slate), Revoked (red). Text remains authoritative; colors are supplementary.
- Active records outside their term display Not yet effective or Expired. An ended/revoked/suspended standing takes precedence.
- The face shows token number and current owner address. ENS, job titles, responsibilities and historical service are not inferred or exposed from private memoranda. Partner authority is not a credential trait.
- Metadata includes a base64 SVG image and human-readable level, rank and standing traits. Existing status/amendment paths emit ERC-4906 metadata update events. Wallet/indexer refresh timing varies; time-based expiry changes the returned metadata but cannot itself emit an event.

## Validation

Run `forge test` in `contributor-review/contracts`. The artwork suite exercises all 48 combinations, expiry and future terms, metadata changes after authorized amendments/status changes, unissued-token rejection, transfer restrictions inherited from the credential suite, and Ethereum's 24,576-byte runtime limit. Exports appear under `out/artwork`.
